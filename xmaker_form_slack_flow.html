Googleフォームの回答を、スプレッドシート記録とSlack通知まで自動でつなぐ

スプレッドシート × Slack 連携の構成イメージ（Google Apps Script）
📝 Googleフォーム問い合わせ・申請・依頼の受付
→
⚙️ GAS（自動実行）回答をトリガーに処理を起動
内容を判定して振り分け
→
📊 スプレッドシート回答を1行追記して記録・一覧化
💬 Slack該当チャンネルへ通知／条件に応じて新規チャンネルを作成し関係者を招待
「継続して直しやすい」ための作り込み
二重処理を防ぐ同じ回答を再実行しても、記録も通知も一度きり（冪等キーで管理）
エラー時の扱いSlack送信やAPI呼び出しが失敗したら自動でリトライ。それでもダメなら管理用チャンネルに通知（放置しない）
ルールは設定シートに「どの回答をどのチャンネルへ」を設定シートの行で管理。仕様変更をコードに触らず反映できる
近い実績：知人経営のガソリンスタンドで、LINE公式アカウント×スプレッドシートを連携し、電話のみだった予約受付・記録・日次の売上管理を自動化（約3ヶ月運用）。Googleカレンダー／Gmail APIを連携し、Web予約→カレンダー登録→確認メール送信までを自動化する予約システムも構築・運用中。
Slackについて：メッセージ投稿・チャンネル作成などのAPI連携は、LINE Messaging APIやフォーム連携と構造が近く、問題なく対応できます。開発にはClaude / Claude Code を日常的に使用しています。
