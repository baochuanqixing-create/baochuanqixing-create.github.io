文字起こしを貼るだけで、要約・決定事項・「誰が・何を・いつまでに」のアクション整理を自動生成。下で実際に試せます。

実サービスの流れ

このページで体験できるのは②〜③の部分です。

① 会議を録音 → ② 文字起こしを自動取得（クラウド / ローカルの2系統） → ③ AIが議事録・アクション整理 → ④ 期限・次回予定を Googleカレンダーへ自動登録 → ⑤ 相手ごとの台帳に時系列で記録

使用技術・設計

Claude / Claude Code Python Whisper・文字起こしAPI（2系統） Google Calendar API MCP連携

金額・日付・人名・約束など、録音に無い情報はAIに生成させず、発言に忠実に整理する制約をかけています。文字起こしはクラウドとローカル（Whisper）の2系統に対応し、録音条件に応じて精度の高い方を採用します。
